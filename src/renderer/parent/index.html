怎么用

  1. 在「配置组」新建一组（例如命名为「B 站」）。
  2. 选择扩展类型：普通站点选「无」；哔哩哔哩选「B 站」。
  3. 在组内增删域名；若选了 B 站扩展，再配置允许的 UP。
  4. 未匹配任何启用配置组的网站一律拦截。
