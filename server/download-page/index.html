为什么选择简行

不是再做一个普通浏览器，而是把「能上什么站」交给家长，把常用浏览能力留给孩子。

🛡

配置组白名单

按组管理可访问域名，组可开关。过滤总开关默认关闭，需要时再打开。

▶

B 站 UP 过滤

给 B 站组挂扩展后，只放行指定 UP 的空间和视频，首页与搜索仍可用。

⭐

收藏夹

文件夹、工具栏、拖拽整理；登录后可上传、拉取，多台电脑共用。

🕘

浏览历史

孩子可以查看并打开记录；删除和清空只在家长设置里进行。

⬇

下载管理

下载文件、查看进度、打开文件、在文件夹中显示，用法接近火狐。

🔑

网站密码

记住网页登录并自动填充。家长密码和同步账号密码不会被保存。

🏠

默认主页

任何人都可以设置主页。启动和新标签页会打开该地址。

☁

账号同步

注册登录后，配置组与收藏夹可以上传到服务器，再拉到其它设备。

家长设置

解锁后集中管理过滤开关、配置组、访问申请、浏览历史和账号同步。本机家长密码不同步。

  • 概览里能看到配置组数量和浏览记录条数
  • 配置组绑定域名，可选挂 B 站扩展
  • 孩子申请观看后，家长在这里同意或拒绝

书签与同步

书签工具栏随时点开常用站点。管理窗口里可以建文件夹、重命名、移动，并和云端对齐。

  • 工具栏书签支持拖拽整理
  • 登录后显示本地 / 云端修订号
  • 上传、拉取收藏夹各一键完成

浏览历史

按天分组，可搜索标题或网址，点击即打开。孩子这边不能删记录。

  • 快捷键 Ctrl+H
  • 今天 / 昨天自动归类
  • 删除与清空只留给家长

下载记录

网页里的文件会保存到系统「下载」文件夹，并留下记录。可以打开文件，或定位到所在目录。

  • 工具栏 ↓ 或 Ctrl+J 打开列表
  • 显示进度、完成状态和大小
  • 清空列表不会删除磁盘上的文件

常见问题

过滤默认是开的吗？

不是。访问过滤默认关闭，家长在设置里打开后，白名单才生效。

历史记录孩子能删吗？

不能。查看和打开可以；删除、清空只在家长设置里。

家长密码会同步吗？

不会。同步的是配置组和收藏夹。家长密码只存在这台电脑。

支持哪些系统？

提供 Windows x64 安装包和 Android APK。两端可用同一账号同步配置组和收藏夹。
